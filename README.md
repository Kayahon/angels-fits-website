# Angel's Fits website

Design files for the Angel's Fits website: cowgirl, festival and party outfit rental in Mactan, Lapu-Lapu City, Cebu.

- `design/` holds the approved page designs (Home, Outfits, How It Works, Book) and `styles.css`. Open `design/index.html` in a browser to view them.
- `design/cursor-snippet.html` is the trailing cursor code, and `design/preview-cursor.html` is a Home preview with it switched on.
- `photos/` holds the outfit photos, and `content/` holds the logo and the original text.
- `website-plan.md` is the build plan for the WordPress + Elementor site.
